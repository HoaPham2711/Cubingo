# Bài học riêng của app

Bài học chỉ đúng cho app này (nghiệp vụ, thiết bị, dịch vụ riêng) — mỗi bài một file trong thư mục này + một dòng ở
danh sách dưới. Thư mục này thuộc app (lớp seed): lệnh đồng bộ lõi không đụng tới. Bài học chung của template ở thư mục
cha (lớp đồng bộ — không sửa tại app; bài học chung mới thì đưa về repo template).

Chưa có bài nào.
